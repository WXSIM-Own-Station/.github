## Inside WXSIM

WXSIM is a local Windows forecast app with a named wxsim desk, a short forecast list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a station you already keep and holds only the model that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra models wait for their own title. WXSIM starts with a local profile and does not need a complex account system.

The wxsim desk stays on a station you already own. Untitled models stay off the live list.

## Quick Start with WXSIM

1. Open the last WXSIM session on a station you keep, not a new empty model.
2. Read the wxsim desk and the last handoff.
3. Finish one visible model view inside WXSIM.
4. Write what changed, then close with a shorter forecast list than you found.
5. If the desk feels crowded, drop anything that belongs to a different station.
6. Leave the wxsim desk on a station you already own.
